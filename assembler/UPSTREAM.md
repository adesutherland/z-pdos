# Mainframe Classic Assembler origin

This is an original implementation by Adrian Sutherland, under MIT. It does
not derive from as370 or another inherited assembler implementation or opcode
table. Architecture and object-format facts used for original code and tests
are cited in [the machine source record](../machines/UPSTREAM.md).

There is no imported assembler baseline to archive. The implementation is
maintained directly in `src/`; Git preserves earlier versions.
