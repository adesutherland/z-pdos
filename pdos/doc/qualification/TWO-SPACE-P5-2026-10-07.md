# PD-003 P5 selectable normal image, 7 October 2026

P5 is complete. A source-built 3390 disk now IPLs through PLOAD and the C31
handover into K, which starts U PCOMM. The normal core begins with no U image
mapped. PCOMM launches native CMS and TSO commands, presents their results,
recovers from an absent command and returns to K for shutdown. A separate
faulted-PCOMM IPL proves K emergency output and cleanup. P6 owns the full
unchanged workload matrix and default selection; this remains an explicit
opt-in source-build route and does not change the 0.1.1 release.

## Implementation

`twospace_normal.S` selects the normal supervisor boot. The real interruption
entry and K64/C31 service gate are shared product sources in
`twospace_entry64.inc` and `twospace_nucleus64.inc`; the diagnostic fixture
includes those same sources. Normal boot publishes no diagnostic U code or
request pages. The guest C31 handover constructs both DAT trees from the
checked sparse disk package. Its live invalidation check uses a private K
page, since the normal U map deliberately starts empty.

K starts PCOMM through the existing native image/invocation path. PCOMM keeps
its maintained `system()` and ATTACH/WAIT/DETACH flow. The normal K endpoint
resolves CMS RUN 24/31 and ordinary TSO member names through the P3 registry,
uses mode-appropriate copied parameters and stacks, restores fixed overlays,
and completes the existing parent-owned TCB/ECB. Writable cached modules are
refreshed only after complete private input validation and while unleased.

The frozen 32-byte result is now readable by U PCOMM through neutral SVC200
operation 35. Requests use the normal version/size header, checked full-width
U destination and active PDOS owner. PCOMM reports a valid application RC;
an absent member displays `OS=28 RC=unavailable`. Failed launch attempts have
paired transcript boundaries and no invented application result. This also
fixes a completion-receipt word that had inadvertently selected the context-
replacement return branch on failed ATTACH.

K-only supervisor SVC199 emits final shutdown or emergency text after the U
root has been reaped, then commits and reads back the transcript. It rejects
problem-state calls and active invocations. The normal nucleus confines U
faults through the invocation gate and keeps K faults on the fail-stop path.

## Repeatable route

`pdos/scripts/two-space-normal.crexx` owns the source build;
`two-space-command.crexx` owns U PCOMM/presentation construction;
`two-space-normal-gate.crexx` creates a fresh disposable disk and drives the
normal prompt/command/shutdown gate, with an explicit `rootfault` option for
K emergency qualification. See the [operator guide](../user/TWO-SPACE.md).
P6 will add the required native profiles and application/file workloads to
this normal route, qualify the bounded failure and terminal matrix, and only
then select it as default.
