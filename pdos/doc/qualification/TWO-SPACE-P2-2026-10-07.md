# PD-003 P2 selected services, 7 October 2026

P2 closes the selected K service surface against P0's native layouts and
P1's invocation ownership. This is a diagnostic guest result. Native
same-personality application calls and general loader residency are P3;
normal-image workload/profile qualification remains P5/P6.

## Implementation and contract reconciliation

CMS FINIS now publishes the selected opaque variable-record output through
an explicitly allocated PDOS.STORE FB extent. Each key has two banks; K
writes and reads the inactive payload before publishing its versioned,
hashed header. A failed write cannot replace the earlier committed file.
CMS STATE/RDBUF and ERASE see the durable state across invocation ownership.
A native empty CMS text file keeps its one-blank-record convention.

The selected TSO SVC99 DD bindings, RDJFCB/OPEN/CLOSE, OBTAIN/DEVTYPE,
BLDL/FIND and READ/WRITE callbacks run in K C31. DDs, open DCBs, cursors and
staging buffers are token-owned. K validates complete U spans before using
C pointers; native AMODE24/31 register widths and LP64 marshalled lists
remain distinct. Direct AMODE64 legacy lists fail explicitly. K supplies
unprivileged U callbacks for record I/O, CHECK, native exits and the selected
CVT TRKCALC compatibility entry. Record completion posts the owning ECB and
residual before native WAIT/CHECK can observe success. A zero-length CKD
record is accepted only with the exact EOF status, full residual and expected
CCW address; a channel error cannot become EOF.

TPUT/TGET, CMS24 WAITRD and CMS31 LINERD share the invocation-owned K driver.
Native input waits for actual attention and data events, preserving empty
Enter, leading/trailing blanks and IBM1047 bytes. The unchanged TSO bridge's
256-byte capacity is supported. K drivers, file buffers and the larger C31
service remain outside U low storage. The extra U compatibility page is at
10000 inside P0's already reserved 0–1ffff interface interval, so it does
not consume the measured application placement gap.

The actual unchanged native path exposed TRKCALC, CHECK/WAIT and LINERD's
56-byte list/fence-at-48 form. The ABI inventory resolves them from producer
source, native instructions and qualified one-space behavior before P2
acceptance. LINEWRT retains its different fence at 44. No application binary
was edited. The diagnostic 31-bit entry bridge now saves its full U64 return
address in U memory, rather than relying on upper register halves that the
31-bit ABI need not preserve.
