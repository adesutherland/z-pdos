## Implementation

The active invocation descriptor selects personality, AMODE, image and runtime
owners. Program-counter ranges no longer select native service ownership.
K checks the interrupted U ASCE, key, problem state, primary ASC and permitted
AMODE before applying that descriptor. Image-cache mappings have explicit
invocation leases; child allocations, open cursors, unfinished output, saved
lowcore, terminal leases and pending reads have invocation tokens and handles.
The compatibility page is saved on every entry and restored on every return.

The interruption nucleus has eight bounded 512-byte contexts. Each retains
all sixteen full-width GPRs, sixteen FPRs, access registers, FPC, old PSW and
ASCE. K enables AFP before using the architectural floating-point save path.
Normal and fault return restore the complete caller context before publishing
separate OS status and application RC. The C31 service stack has four K-only
pages; none consumes low U storage.

Synchronous SSCH and asynchronous CSCH completion use an enabled interruption
wait. TSCH status decides success; clear must report its clear-function bit
before K releases or reuses the channel workspace. A saved/restored clock
comparator detects stalls. I/O interruption dispatch retains the physical
subchannel and interruption parameter. Disk and terminal real workspaces
remain separate. A retired terminal completion is keyed by its old token and
handle, so a retry owner cannot acquire it.

The existing PCOMM diagnostic source is retained as supporting launch code.
Its earlier command pass is not substituted for native P3 or normal P5
acceptance. The bounded corrupt-stage control remains opt-in.
