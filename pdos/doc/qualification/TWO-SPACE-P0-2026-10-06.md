## P3 fixture correction, 7 October 2026

Native execution exposed two bytes of natural fullword alignment inserted by
`DC A` after the CMS24 parent's SVC202. CMS202 requires its continuation
word immediately after the instruction. The source now uses `DC AL4`, which
emits that exact four-byte native form without alignment padding. This fixes
the source-built control; no released application binary is edited. The
re-frozen build is `build/pdos/p0-native-contract-5/`, with its exact source
and artifact hashes in the same receipts. The package inventory and all
other native call contracts remain the original P0 inputs.

The Classic CMS producer's header is also distinct from the released ELF
MODULE header: words 8–15 encode the last text-record index and length,
not the executable end address. Byte 44 declares AMODE, bytes 45–47 are
`ESD`, and trailing records contain 20-byte symbol entries. These fixtures
are fixed at their declared origin because they contain no base relocation
records. P3's loader validates this native form explicitly and uses the
same checked reversible overlay for nested fixed-origin calls.
