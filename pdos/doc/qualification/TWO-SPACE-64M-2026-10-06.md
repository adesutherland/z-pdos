# Two-space 64 MiB real-memory profile, 6 October 2026

The diagnostic successor now boots with 64 MiB real storage. Its 64-bit
region-first DAT maps the entire real profile through K's C31-accessible
`0x08000000`–`0x0bffffff` aperture. U does not map that aperture. The
guest builds K tables in real `0x100000`–`0x17ffff` and U tables in real
`0x180000`–`0x1bffff`; K aliases them at `0x05000000` and `0x05080000`.
The disk and console each retain a separate K-only 64 KiB low-real channel
workspace at `0x1c0000` and `0x1d0000`. Every channel-program pointer
remains below the 24-bit real limit. None consumes 24-bit U virtual space.

The full-width host DAT builder used 397,312 K table bytes and initially
94,208 U table bytes, within 512 KiB and 256 KiB pool capacities. The
fresh IPL guest built the same ASCEs and table bytes; live CMS24/CMS31
mapping and the guarded stack raised U table use to 122,880 bytes. The
host diskless machine gate passed 87 checks at
`build/pdos/two-space-64m-build2/run/receipt.json`. The disposable 3390
IPL passed 108 checks at `build/pdos/two-space-64m-ipl/run/receipt.json`,
including guest DAT construction, CKD/3270 services, terminal input,
absent-subchannel failure, both CMS image maps, the AMODE24 stack write,
nested overlay restoration and event-observed disabled wait. Its disk
SHA-256 was
`04e82292fc01bd46de45d5b284b4169d8eacd4b74a0cb6729aaefc5bd657fbfa`;
source core SHA-256 was
`e4dd6ac79d523dcf1820922783d50aa11732e1c1852779d076ec78db5808c16e`.

The first 64 MiB build reached the host gate test but exposed one test
source still using the removed equal-pool constant. Updating that test to
attach the named U pool produced the passing build above. The test OS
continues to reject an allocation as large as the whole real profile;
this does not measure the largest usable application heap. The U24
virtual placement gap remains 13,914,112 bytes, separate from real
storage capacity. The new profile is diagnostic and does not select the
normal `PDOS.SYS` replacement or qualify unchanged CMS/TSO execution.
