## Implementation and supported boundary

The existing C90 EDIT core now has one shared UTF-8 controller for actual
editable 3270 fields and line commands: insert/delete, find/change, one-level
undo, paging, horizontal movement, SAVE, SAVE AS and guarded exit. VM/CE
Community Edition MECAFF EE by Hans-Walter Latz is the interaction reference,
pinned at `1694fa893eb962ef1dca156247c6c3cca1750ac8`. No EE/THE code is imported.
See the [design](../architecture/RECORD-EDITOR.md) and
[commands and limits](../user/APPLICATIONS.md).

Operation 38 reads supported PS/PDS members and compares before saving through
the existing native TSO two-bank STORE on the IPL volume. Native readers and
batch DDs observe the journal member; physical PDS directories are not rewritten.
A SHA256 token binds name, record attributes, existence and native bytes.
Changed/busy/full/invalid refusals retain the old data and dirty buffer.
Publication I/O12 can be uncertain; the buffer and prior generation remain,
and identical committed content can be reconciled by retry. Physical power-loss
and device-fault behavior were not injected on the guest.

The bounded profile is 4096 records, 256 UTF-8 bytes per record, at most 256
native bytes per record and 64 KiB packed native input. IBM1047 FB/VB conversion
is explicit; binary DD bytes are unchanged. The actual 3215 command route is
ASCII and limited to 148 input characters. Accented source data is qualified
through a 3270 data field. A clean saved-session reconnect is supported;
unsaved-session crash recovery is not provided. Read Modified selects fields;
Read Buffer preserves exact columns, including interior nulls. Terminals
without Read Buffer use the line interface.

BATCH now displays FORM OPEN, BATCH as its input owner and its actual PF-key
legends. STEP/DD changes say they filter retained output. The normal console
returns on exit. CAPTURE GAP after raw EDIT is an explicit opaque-screen
history boundary, not a claim that retained batch DD output is missing.

## Repairs and lessons

Review repaired interior-null positions, attribute checks on identical-content
retry, physical-source origin reporting, runtime veneer selection and stale
K nucleus reuse before the physical matrix. Initial staging refused before
IPL because a cREXX block-local editor flag was empty in verification; a
procedure-scope declaration repaired it. Manual screen inspection then found
the shell-name branch overwrote BATCH's owner label; its guard and actual
screen assertion were repaired and the affected cheap cell repeated.

The first restart attempt kept a completed OWNER job, so existing serial
retention policy refused RUN with status4 before any compiler step. This was
not a compiler or memory failure; shutdown recovery of that attempt was not
accepted. The corrected fixture/runbook reviews and purges the completed job
before starting the next. A later successful chain initially reported 29/31
because the oracle wrongly expected permanent GOLINK. Review of unchanged
CRXLGO and the stopped storage corrected that expectation; the same successful
execution re-evaluates to 30/30 without replay. The exact new output marker,
all four native outcomes and absence of temporary residue remain required.

The first real3215 cell failed before compilation because the fixture expected
a guest rejection of accented input. Hercules substituted a dot first; durable
readback proved `caf.!`. F6 preflights printable ASCII before any adapter send,
with a no-send host control and an actual unchanged guest INPUT count. The
C decoder's native non-ASCII refusal is checked separately. The line route is
ASCII; no product/configuration change or wider text-input claim is made.

Raw traces, cores, readbacks, detailed receipts and disposable media are retired
after independent acceptance and consumer release. Retain this concise result
and the explicitly requested final manual PNGs/PDFs only. The Operator completed maintenance handback after acceptance of all five
cells. Independent checks find no PDOS leases/process registration and no
task QA/media/input/freeze/probe artifacts. Only one concise private handback
summary remains. Normal current K/U/EDIT producers and shared build inputs are
preserved; both final PDFs and sixteen selected PNGs retain their identities.
This closes the approved PD-027 increment and selected PD-033 Stage 6
development qualification. Commit, publication, managed adoption and release
selection remain separate.
