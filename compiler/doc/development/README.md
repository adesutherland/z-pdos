# Mainframe Classic C development

Run maintained cREXX recipes from the repository root. [User instructions](../user/README.md)
identify dependencies and commands; tests are in `../../tests/`. Keep generated
objects, executables and logs below the ignored root `build/` directory.

[BACKLOG.md](../BACKLOG.md) is the only live roadmap, defect and qualification
queue. Use [the shared workflow](../../../doc/WORKFLOW.md), stable `CC-NNN`
identities, evidence and explicit acceptance criteria. A backlog entry does
not authorise implementation.
